# 心动邀请 · 微信小程序版

一个原生微信小程序：创建者生成见面邀请并分享给微信好友，受邀者选择日期、时间、活动和食物，创建者在私密结果页查看回复。

## 当前能力

- 微信身份自动识别，无需邮箱、验证码或密码
- 中文 / English 双语切换
- 创建专属邀请并分享小程序卡片
- 受邀者完成完整 7 屏互动流程
- 创建者预览不会写入正式答案
- “我发出的邀请”列表与私密结果页
- 邀请默认 30 天有效；同一邀请只接受第一份正式答案
- 云函数校验输入，数据库不直接暴露给客户端

## 项目结构

```text
miniprogram/                 小程序页面、样式和图片
cloudfunctions/              微信云开发云函数
project.config.json          微信开发者工具项目配置
```

## 第一次运行

1. 安装微信开发者工具稳定版并用管理员微信扫码登录。
2. 克隆或下载本仓库，在开发者工具中选择“导入项目”。
3. 项目目录选择仓库根目录；AppID 已配置为 `wx85ec75e4a6285e41`。
4. 在开发者工具顶部点击“云开发”，开通一个按量付费/免费额度环境。
5. 在云开发数据库中创建集合：`invitations`。
6. 将该集合权限设置为“仅管理员可读写”。所有业务访问均经过云函数。
7. 在 `cloudfunctions` 下依次右键每个云函数，选择“上传并部署：云端安装依赖”：
   - `createInvitation`
   - `getInvitation`
   - `listInvitations`
   - `getResult`
   - `submitResponse`
8. 点击“编译”，再用“预览”二维码在手机微信中测试分享流程。

## 测试正式回答

创建者本人打开邀请时会自动进入预览模式，因此需要用另一个微信账号打开分享卡片，才能测试正式提交。提交后，创建者回到首页下拉刷新，或进入对应结果页查看。

## 下一阶段：微信订阅通知

目前答案会即时保存并显示在结果页。待小程序后台申请到合适的“订阅消息模板”后，再配置模板 ID 和字段，受邀者提交时即可向创建者发送微信服务通知。不要把 AppSecret、上传私钥或其他密钥提交到 GitHub。
